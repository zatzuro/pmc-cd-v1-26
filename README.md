# Calendario Directivo PRISA Media Colombia — V1.0

Frontend estático del piloto septiembre–diciembre de 2026.

## Alcance

- Calendario mensual en escritorio.
- Agenda cronológica en móvil.
- Búsqueda y filtros por tipo, comercialización y disponibilidad.
- Creación, consulta, edición y eliminación de eventos.
- Festivos y días especiales diferenciados.
- Integración con una API de Google Apps Script.

La API y la configuración de Google Sheets se administran fuera de este repositorio público.

## Publicación

GitHub Pages publica automáticamente el sitio mediante el flujo incluido en `.github/workflows/pages.yml`.
